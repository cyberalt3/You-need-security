## What is Trail of Bits Skills?

**Trail of Bits Skills** is a collection of AI coding agent skills created by **Trail of Bits** — one of the world's leading security research and consulting firms. These skills augment AI agents with specialized capabilities for security research, vulnerability detection, and audit workflows.

## What is it for?

This repository provides **expert-level security skills for AI coding agents**:

- **Security audit workflows** — Structured methodologies for conducting code security audits with AI assistance
- **Vulnerability detection** — Specialized prompts and techniques for finding security bugs
- **Security research** — Skills for analyzing binaries, smart contracts, and other targets
- **Best practices** — Trail of Bits' decades of security expertise encoded as agent skills
- **Audit automation** — Streamline the repetitive parts of security audits

## How Does It Work?

1. **Skill Installation** — Install the skills into your compatible AI coding agent (Claude Code, Codex, etc.)
2. **Skill Activation** — Invoke a specific skill when performing a security-related task
3. **Guided Analysis** — The skill provides structured methodology, prompts, and checklists for the AI agent to follow
4. **Expert Techniques** — Each skill encodes Trail of Bits' security expertise into actionable steps
5. **Output** — Structured findings, reports, and recommendations following industry-standard formats
