## What is PentAGI?

**PentAGI** is a fully autonomous AI agent system capable of performing complex penetration testing tasks. Built by **VXControl**, it uses a multi-agent architecture where specialized AI agents collaborate to plan, execute, and report on penetration testing engagements — all with minimal human intervention.

## What is it for?

PentAGI provides a **self-hosted, autonomous penetration testing platform**:

- **Fully autonomous testing** — AI agents plan and execute penetration tests without step-by-step guidance
- **Multi-agent collaboration** — Specialized agents handle different phases (recon, exploitation, reporting)
- **Self-hosted** — Run on your own infrastructure for complete control over sensitive testing data
- **LLM-agnostic** — Works with OpenAI, Anthropic, and other LLM providers
- **Web UI** — Interactive dashboard (React + GraphQL) for managing and monitoring tests

## How Does It Work?

1. **Task Definition** — Define a penetration testing objective through the web UI or API
2. **Agent Orchestration** — The system spawns specialized agents for different tasks (reconnaissance, vulnerability scanning, exploitation, etc.)
3. **Autonomous Execution** — Agents work collaboratively, sharing context and findings while executing tools and techniques
4. **Real-Time Monitoring** — Watch agents work in real-time through the React-based dashboard
5. **Comprehensive Reporting** — Agents compile their findings into actionable reports with evidence and remediation steps
